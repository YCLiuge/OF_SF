# 个人进度导入

使用尚未进入过游戏的新区服账号，在启动器选择「导入角色进度」。选择全进度备份 ZIP、包含 snapshot.json 的目录或 snapshot.json。选择 private-server-import.json 时，启动器会读取同目录的 snapshot.json。单独一份 private-server-import.json 无法导入。

使用本区服独立账号登录。备份工具里的 `playerId` 对应游戏 HUD 的 UID，「角色」对应玩家名。预览会说明两者在所选区服是否可用。若有占用，可选本服分配的 UID、沿用本服名字或另起名字。选定后确认。首次进游戏前可撤销，已游玩的账号请另建角色导入。

| 可迁移内容 | 映射范围 |
| --- | --- |
| 队长、探索员及编队 | 队长等级、经验、世界等级、备份中有效的当前头像、探索员等级、突破上限、星级、可识别技能等级，以及三人编队 |
| 剧情和成就 | 国服目录中的常驻剧情任务、条件状态和进度、章节已领奖标记，及可识别的个人成就计数 |
| 背包、服饰及染色 | 本服表能识别的材料、食物、家具等普通堆叠物品，服饰、染色方案和颜色。按原编号恢复三套穿搭、13 个穿戴槽、每槽选中的染色方案，以及饰品和发辫的隐藏选项。缺失的染色方案回落到该件服饰的默认色 |
| 武器、防具和映像 | 装备模板、受上限约束的等级/强化/星级。以新实例重新关联编队角色的装备预设，随机词条由本服生成 |

手机号、渠道账号、会话、设备、权限、付费记录、好友、聊天、其他玩家、排行榜、地图摆设、各图探索总分与收集点、宠物和完整铭刻留在原服。源文件中缺失或本服资源表无法识别的记录会跳过。

## 剧情与登录位置

预览会列出接续场景和进行中的剧情任务编号。确认后，角色回到备份登录时所在的自由探索地图。能找到同地图、同原服频道中该角色自己的位置和朝向时，两者一起恢复。缺坐标时使用该图的出生点，进入区服配置的默认公共频道。

仍在瓶中小径的角色会留在教学地图。备份中有装置 101 已开启记录时会保留该状态。风车处可以先接到首个任务，单有这一记录还不足以判断已经进广场。旧备份缺少登录场景时，已推进广场任务或领过章节奖励的角色从罗塔花园广场接续，其余从瓶中小径接续。导入保留可核对的目标进度和已领奖记录；没有逐步教学记录的过场动画可能再次播放。

启动器在本地解析备份，发送选定区服恢复游戏所需的 UID、公开角色名与进度字段。渠道登录凭据、付款记录和原始报文留在本机。服务器重新核验目录、类型和上限。预览不创建游戏角色。确认导入时在同一事务内创建角色并保存进度，重复提交同一张预览单不会重复获物。预览和专用登录票各有效 10 分钟。公网使用玩家 TLS 网关。


## 服主运维

按[公网玩家接入](公网玩家接入.md)启动区服和 TLS 网关。玩家在启动器选择同一个域名并登录。远端仅开放玩家网关的端口，账号服务和游戏服务监听本机回环地址。

预览的 JSON 上限为 2 MiB，确认和撤销各为 2 KiB。网关最多同时处理 4 个预览上传，每个上传限时 30 秒。每个真实来源每分钟最多提交 60 个网关 POST，后端对注册、登录及其他账号请求分别计数。返回 413 时请确认使用启动器选择本地文件，返回 429 时稍后重试。401 表示需要重新登录，预览单过期后须重新预览。

区服启动及运行期间每分钟自动清理过期的导入票和预览。导入收据独立持久保存，进入游戏或撤销后清理对应的撤销明细。跨机器迁移使用区服原有的全状态备份，同时迁移账号库与游戏库。
