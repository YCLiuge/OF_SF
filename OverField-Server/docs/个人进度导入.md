# 个人进度导入

使用尚未进入过游戏的新区服账号，在登陆器选择「继承已有存档」。选择全进度备份 ZIP、包含 snapshot.json 的目录或 snapshot.json。选择 private-server-import.json 时，启动器会读取同目录的 snapshot.json。单独一份 private-server-import.json 无法导入。

使用本区服独立账号登录。备份工具里的 `playerId` 对应游戏 HUD 的 UID，「角色」对应玩家名。预览会说明两者在所选区服是否可用。若有占用，可选本服分配的 UID、沿用本服名字或另起名字。选定后确认。首次进游戏前可撤销，已游玩的账号请另建角色导入。

| 可迁移内容 | 映射范围 |
| --- | --- |
| 队长、探索员及编队 | 队长等级、经验、世界等级、备份中有效的当前头像、探索员等级、突破上限、星级、可识别技能等级，以及三人编队 |
| 剧情和成就 | 常驻剧情、一次性支线、番外和 NPC 委托的原始状态与条件进度，章节领奖标记及可识别的个人成就 |
| 历史任务 | 有编号且条件匹配的日常、随机、活动关联和未分型任务单独归档。区服按自己的活动排期与刷新规则决定当前任务 |
| 背包、服饰及染色 | 本服表能识别的材料、食物、家具等普通堆叠物品，服饰、染色方案和颜色。按原编号恢复三套穿搭、13 个穿戴槽、每槽选中的染色方案，以及饰品和发辫的隐藏选项。缺失的染色方案回落到该件服饰的默认色 |
| 武器、防具和映像 | 装备模板、受上限约束的等级/强化/星级。以新实例重新关联编队角色的装备预设，随机词条由本服生成 |
| 生活采集 | 原登录地图中属于本角色的植物、木材、矿石、昆虫、取水及拾取累计。全进度样例已核对其中五类有记录的项目。导入后的每日与幸运额度从零开始 |

区服启用初始全解锁时，导入角色可用 542 件服饰、768 种家具、207 个头像、231 项动作菜单和 314 个聊天表情。角色当前穿搭、染色、隐藏选项和所选头像按备份恢复。徽章、雨伞以及八个工具和载具装备槽的穿戴选择尚未迁移。

本机隔离区服用一份全进度备份完成导入、撤销、重新导入及重启后的原生协议登录。核对了 27 名探索员的 81 套穿搭、各槽染色方案与所选头像，也核对了区服回传的完整收藏目录和花费后的余额。这项验证读取登录和背包回包，界面逐项点选另行验收。

宠物按背包及宠物列表中的明细恢复，包括名称、等级、性格、完整度与属性、异色、捕获地点和时间、体型与重量。出战状态会绑定到本服新分配的实例，仓库容量随备份恢复。若只导出了宠物总数，预览会列出有明细的数量；例如总数 3、有明细 1 时可恢复 1 只。宠物徽章暂未迁移。 登陆器会先查询区服支持的导入项目。旧区服无法接收的宠物和区域记录会在确认前列明，原始备份可以留待升级后使用。

手机号、渠道账号、会话、设备、权限、付费记录、好友、聊天、其他玩家、排行榜、地图摆设、各图探索总分与逐个收集点的状态和完整铭刻留在原服。源文件中缺失或本服资源表无法识别的记录会跳过。

## 剧情与登录位置

任务号与条件同时匹配时，导入器才接续进度。一次性任务已完成的原始次数会保留。出现多次完成后又回到进行中的记录时，区服将其存为历史。缺少编号且无法通过剧情条件识别的行计入跳过记录。导入过程不触发领奖。

预览会列出接续场景和进行中的剧情任务编号。确认后，角色回到备份登录时所在的自由探索地图。能找到同地图、同原服频道中该角色自己的位置和朝向时，两者一起恢复。缺坐标时使用该图的出生点，进入区服配置的默认公共频道。原版客户端加载场景时还会校验地面和可用传送点。实测一个探索率 0% 的新角色收到了远端地标的存档坐标，进图后仍落在樱庭世界·昼的出生点。

仍在瓶中小径的角色会留在教学地图。备份中有装置 101 已开启记录时会保留该状态。风车处可以先接到首个任务，单有这一记录还不足以判断已经进广场。旧备份缺少登录场景时，已推进广场任务或领过章节奖励的角色从罗塔花园广场接续，其余从瓶中小径接续。导入保留可核对的目标进度和已领奖记录；没有逐步教学记录的过场动画可能再次播放。

启动器在本地解析备份，发送选定区服恢复游戏所需的 UID、公开角色名与进度字段。渠道登录凭据、付款记录和原始报文留在本机。服务器重新核验目录、类型和上限。预览不创建游戏角色。确认导入时在同一事务内创建角色并保存进度，重复提交同一张预览单不会重复获物。预览和专用登录票各有效 10 分钟。公网使用玩家 TLS 网关。


## 区域装置与挑战

预览按项目列出可恢复的区域装置、区域目标、收藏点、世界挑战和限时挑战。场景快照须包含备份角色本人，并与该角色主存档的地图、频道一致。装置保留开关和等级，收藏点保留领奖状态，世界挑战保留胜利记录，限时挑战保留最佳用时。曾经赢得的宝箱在导入后不会重复发放。

只备份了广场或探索百分比时，无法据此恢复某个探索世界的装置等级。已游玩的角色沿用原有存档。老区服先前把同号场景的收藏误记到装置 1001–1003 的计数，现按装置所属点位和明确记载的装置目标核算。

## 服主运维

按[公网玩家接入](公网玩家接入.md)启动区服和 TLS 网关。玩家在启动器选择同一个域名并登录。远端仅开放玩家网关的端口，账号服务和游戏服务监听本机回环地址。

预览的 JSON 上限为 2 MiB，确认和撤销各为 2 KiB。网关最多同时处理 4 个预览上传，每个上传限时 30 秒。每个真实来源每分钟最多提交 60 个网关 POST，后端对注册、登录及其他账号请求分别计数。返回 413 时请确认使用启动器选择本地文件，返回 429 时稍后重试。401 表示需要重新登录，预览单过期后须重新预览。

区服启动及运行期间每分钟自动清理过期的导入票和预览。导入收据独立持久保存，进入游戏或撤销后清理对应的撤销明细。跨机器迁移使用区服原有的全状态备份，同时迁移账号库与游戏库。
