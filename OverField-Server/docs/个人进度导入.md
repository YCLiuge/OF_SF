# 个人进度导入

使用尚未进入过游戏的新区服账号，在启动器选择「导入存档」。选择全进度备份 ZIP、包含 snapshot.json 的目录或 snapshot.json。选择 private-server-import.json 时，启动器会读取同目录的 snapshot.json。单独一份 private-server-import.json 无法导入。

先预览可映射条数，再确认导入。登录和注册使用本区服独立账号。导入沿用本服 UID 和昵称，包括首次入场时的命名流程。已经进入游戏的角色受保护。如需保留原角色，可另建账号导入。进入游戏前可以撤销，重新登录启动器后也可以撤销。首次进入游戏即关闭撤销，防止已经交易或使用的道具再次出现。

| 可迁移内容 | 映射范围 |
| --- | --- |
| 队长、探索员及编队 | 队长等级、经验、世界等级、探索员等级、突破上限、星级、可识别技能等级，以及三人编队 |
| 剧情和成就 | 国服目录中的常驻剧情任务、条件状态和进度、章节已领奖标记，及可识别的个人成就计数 |
| 背包、服饰及染色 | 本服表能识别的材料、食物、家具等普通堆叠物品，服饰、染色方案和颜色。按原编号恢复三套穿搭、13 个穿戴槽、每槽选中的染色方案，以及饰品和发辫的隐藏选项。缺失的染色方案回落到该件服饰的默认色 |
| 武器、防具和映像 | 装备模板、受上限约束的等级/强化/星级。以新实例重新关联编队角色的装备预设，随机词条由本服生成 |

导入不迁移手机号、账号、昵称、UID、会话、设备、权限、付费余额、订单、好友、聊天、其他玩家、排行榜、活动状态、地图摆设、宠物、完整铭刻或原服位置。角色从瓶中小径或罗塔广场起步，取决于已恢复的序章进度。源文件中缺失、暂未映射或本服资源表没有的记录会跳过。

启动器只在本地解析完整备份，发送数值白名单投影。服务器重新核验目录、类型和上限。预览不创建游戏角色。确认导入时在同一事务内创建角色并保存进度，重复提交同一张预览单不会重复获物。预览和专用登录票各有效 10 分钟。公网使用玩家 TLS 网关。


## 服主运维

按[公网玩家接入](公网玩家接入.md)启动区服和 TLS 网关。玩家在启动器选择同一个域名并登录。远端仅开放玩家网关的端口，账号服务和游戏服务监听本机回环地址。

预览的 JSON 上限为 2 MiB，确认和撤销各为 2 KiB。网关最多同时处理 4 个预览上传，每个上传限时 30 秒。每个真实来源每分钟最多提交 60 个网关 POST，后端对注册、登录及其他账号请求分别计数。返回 413 时请确认使用启动器选择本地文件，返回 429 时稍后重试。401 表示需要重新登录，预览单过期后须重新预览。

区服启动及运行期间每分钟自动清理过期的导入票和预览。导入收据独立持久保存，进入游戏或撤销后清理对应的撤销明细。跨机器迁移使用区服原有的全状态备份，同时迁移账号库与游戏库。
