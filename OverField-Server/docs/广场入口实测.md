# OF_SF 广场入口实测

国服 TapTap PC 1.1.12 的实机广场右上角有两行共 12 项。下表按当时界面从左至右排列。角色进度、场景与活动排期会改变可见入口。服务端的隔离角色测试覆盖具体操作，整页能打开不代表每个按钮均已接入。

| 入口 | 已核对的操作及限制 |
| --- | --- |
| 手册 | 可读取 102 项手册标记。解锁及领奖仍返回失败。 |
| 任务 | 已验证序章接取、两个 NPC 区域的对话、教学招募以及领奖。后续主线尚未逐章验证。 |
| 招募 | 常驻及配置的 UP 池支持单次、十次、保底和历史。已修正主线尚未进到教学招募时常驻单抽误报「参数错误」的问题。玩家已在修复后的原客户端连续完成常驻单抽，未再出现抽完弹「失败」。补齐了抽取后原客户端上报的场景互动状态，协议测试同时检查映像图鉴和招募记录刷新。常驻默认概率按国服说明设置，服主可调。 |
| 时装 | 套装切换、部位隐藏、存档及同步通过。新染色操作尚未接通。 |
| 星云树 | 双角色协议测试覆盖 8 页共 198 个节点的消耗、前置、75 项能力和 8 份核心奖励，验证了重登和防止重复领奖。夜樱背包格与昆虫观察的奖励据国服道具表补配。未接入的成就事件仍需还原。 |
| 探索员 | 已验证招募入队、编队、装备强化、锁定与铭文。角色成就领奖尚未接通。 |
| 宠物 | 可读取列表。捕捉、改名、分解及出战仍返回失败。 |
| 许愿 | 对应周年许愿活动。原版右上角控件打开活动 260326131，可查看活动进度、提交愿望，并按真实登录日领奖。 |
| 祈愿树 | 用本期指定资源兑换节点奖励。节点按前置解锁，已兑状态按角色和期数保存。已对有原表排期的 63 期共 911 个节点逐项验证，覆盖跨层、分支、实扣、装备/服饰/映像入库、重复点击与重登。另有 14 张布局没有开放排期。 |
| 活动 | 已接入七日签到、每日甜点、新人支援、部分收藏活动及通行证。转盘等其他活动仍需补齐。 |
| 通行证 | 可查当期任务与等级、累计已有玩法进度、领取达标奖励。已随高级礼包发放的奖励沿用发放记录。 |
| 装饰 | 家具摆放、搬移、回收、跨频道隔离及重登保存通过。一键收起、家园方案、房间装饰、点赞仍未完成。 |

「招募」消耗招募券，进入抽取流程。「祈愿树」按节点标价扣除活动资源，兑换指定物品。「许愿」使用独立的活动任务和登录进度。
