# OF_SF 广场入口实测

国服 TapTap PC 1.1.12 的实机广场右上角有两行共 12 项。下表按当时界面从左至右排列。角色进度、场景与活动排期会改变可见入口。服务端的隔离角色测试覆盖具体操作，整页能打开不代表每个按钮均已接入。

| 入口 | 已核对的操作及限制 |
| --- | --- |
| 手册 | 国服配置有 18 个普通手册标记、102 个秘境标记。角色在对应地图发现后可在手册领 1,000 金币，每个标记只领一次。列表按角色保留发现、领奖与秘境任务完成数。 |
| 任务 | 用同一名新角色连续走完序章九节共 50 步，逐节核对奖励和下一项任务，重登后进度保留。[逐章进度与验证方式](剧情对照.md) |
| 招募 | 常驻及配置的 UP 池支持单次、十次、保底和历史。已修正主线尚未进到教学招募时常驻单抽误报「参数错误」的问题。玩家已在修复后的原客户端连续完成常驻单抽，未再出现抽完弹「失败」。补齐了抽取后原客户端上报的场景互动状态，协议测试同时检查映像图鉴和招募记录刷新。常驻默认概率按国服说明设置，服主可调。 |
| 时装 | 套装切换、部位隐藏、存档及同步通过。国服染料、调色、保底、染色槽、保存及穿戴同步已通过双角色原生协议测试。 |
| 星云树 | 双角色协议测试覆盖 8 页共 198 个节点的消耗、前置、75 项能力和 8 份核心奖励，验证了重登和防止重复领奖。夜樱背包格与昆虫观察的奖励据国服道具表补配。79 项探索能力的 389 个升级档位均已用原生请求验证扣费和效果道具替换。文件、水晶等八类收藏会按地图推进对应成就。旧角色从其保存的收藏记录补算，已有领取记录继续生效。部分成就事件仍需还原。 |
| 探索员 | 已验证招募入队、编队、角色升级与突破、技能升级、装备强化、锁定、铭文及三个装备预案。测试覆盖同账号角色借用装备、跨账号隔离及重登。角色成就列表按存档返回等级、星级、突破和已记录进度。36 名探索员的 288 枚纪念章和 554 个配置了奖励的档位已实测发放。另有 22 个档位没有配置奖品，保留未领状态。高级奖励线可在本服直接解锁。 |
| 宠物 | 支持捕捉、改名、出战与收回、放生发料、仓库分页及扩容。已测试其他玩家查看出战宠物和重登恢复。普通捕捉器的成功率采用社区数值。 |
| 许愿 | 对应周年许愿活动。原版右上角控件打开活动 260326131，可查看活动进度、提交愿望，并按真实登录日领奖。 |
| 祈愿树 | 用本期指定资源兑换节点奖励。节点按前置解锁，已兑状态按角色和期数保存。已对有原表排期的 63 期共 911 个节点逐项验证，覆盖跨层、分支、实扣、装备/服饰/映像入库、重复点击与重登。另有 14 张布局没有开放排期。 |
| 活动 | 已接入七日签到、每日甜点、新人支援、部分收藏活动及通行证。节庆扭蛋支持抽取、附赠、记录及售罄结算；照片投稿、沙袋和锦鲤换码见活动管理。 |
| 通行证 | 可查当期任务与等级、累计已有玩法进度、领取达标奖励。已随高级礼包发放的奖励沿用发放记录。 |
| 装饰 | 家具摆放、搬移、回收、跨频道隔离及重登保存通过。支持一键收起、保存和应用三个家具方案、家园点赞及记录。已验证房间装饰、99 种可坐家具的探索员入住及召回。 |

「招募」消耗招募券，进入抽取流程。「祈愿树」按节点标价扣除活动资源，兑换指定物品。「许愿」使用独立的活动任务和登录进度。
