《开放空间》私有玩法服务说明

上游版本为 byzp/of-ps 的 fa2142b8521e802beb23fc6ed538205b9f4f1513。app/upstream/ 包含这次部署使用的真实玩法处理器、协议、数据库和消息构造源码，许可全文在 app/upstream/LICENSE。私服托管代码和对应修改随包提供。通过网络提供这一版服务时应按 AGPL 向使用者提供对应源码，参见许可说明。

游戏服务使用 TCP、原始大端双字节头长度、PacketHead 与协议消息。服务模块依赖 Python 3.12+、protobuf 6.33.5 和相邻的私服身份服务，运行不需要 KCP。未请求远程联服、外部 SDK 或官服账号。游戏服务器通过本服的 identity.sqlite3 核实私服签发的短时一次性票据。同一连接先验证私服票据，接着处理原生玩家登录和主数据请求。默认适合本机运行。局域网与私有 VPN 部署需让身份服务公布客户端实际可达的地址，传输凭据的链路应使用受信网络或加密隧道。

游戏数据写入挂载目录的 game.sqlite。首次成功验证私服资料后，服务在事务内创建角色并写入昵称；旧私服资料若名字为空，将补上该档案当前的有效昵称。已有非空名字会保留。初始主城使用现场核对过的 9999。出生表来自 1.1.12 安装，原版表中的发型、装束、技能与武器由社区的本地初始化逻辑写入。角色的坐标及转向随移动提交，在同一私服重进可恢复。服务器中断后的迁移应使用部署包提供的整目录停服备份，同时保留身份库和游戏库。

已实际测试的服务器流程涵盖私服票据失效及重复使用、首次创建与旧资料空名修复、主城角色和背包主数据、第一帧场景、正确的武器模板、Ping、两名玩家进同场景、坐标 x 为零时的实时移动广播、坐椅响应、重启后的角色名和姿态。测试还覆盖非法包头、越界资源长度以及压缩块限制。包中装载 50 项玩法处理器，其他上游处理器仍需适配。完整任务、战斗、各类玩法数值和原版 1.1.12 Windows 客户端的区服选择与接入尚未做完端到端验证。服务通过的消息测试不等同于实机游戏可玩。

本包参考 of-ps v3.0 及后续提交 0c556ce2303f378151bcab3e533376ac156a8543，补入独立玩家设置及提示进度的读取和写入，可从既有私服存档升级。启动派发沿用国服 1.1.12 的正确版本对。角色昵称已在本地私服档案建立时分配，登录时同步到角色数据。

本版新增了原生私服的第一篇主线两个交谈目标，详见同目录的序章新的伙伴.md。
