# 公网玩家接入

服主准备一个能解析到服务器的域名，例如 `play.example.net`，以及与该域名匹配的 PEM 证书链、私钥。服主可在玩家补丁的「手动连接设置」保存区服，再把单独导出的区服邀请私发给获准参加的玩家。玩家导入邀请后点「测试连接」，注册或登录本区服账号。手动接入可填 `https://play.example.net:18443`，使用自建 CA 时选择服主提供的 PEM 根证书。

## 启动

在服务端目录打开两个终端。先运行游戏区服，Linux 发行包的 `./start.sh` 会选用随包 Python 3.12，Windows 使用 `.\Start-Server.cmd`。首次启动会初始化区服数据和本机转发密钥。下例的 `./state/realm` 是两个进程共同使用的数据目录。

**Linux x86-64**

```sh
# 终端一
OF_ACCOUNT_REGISTRATION=open ./start.sh --state ./state/realm start

# 终端二
./start.sh --state ./state/realm player-gateway --listen 0.0.0.0 --port 18443 --cert /etc/of-sf/fullchain.pem --key /etc/of-sf/privkey.pem
```

**Windows x64（PowerShell）**

```powershell
# 终端一
$env:OF_ACCOUNT_REGISTRATION = 'open'
.\Start-Server.cmd --state .\state\realm start

# 终端二
.\Start-Server.cmd --state .\state\realm player-gateway --listen 0.0.0.0 --port 18443 --cert C:\OF_SF\certs\fullchain.pem --key C:\OF_SF\certs\privkey.pem
```

对外放行 TCP 18443。有 NAT 时把这个端口映射到网关。内部账号 HTTP 和原生游戏 TCP 默认分别监听 `127.0.0.1:18881`、`127.0.0.1:11033`。修改内部端口时，为两个终端设置相同的 `OF_HTTP_PORT`、`OF_GAME_PORT`，并保持 `OF_BIND=127.0.0.1`。公网 TLS 在网关终止，内部账号服务使用回环 HTTP。域名证书须覆盖客户端填写的主机名；直接填写公网 IP 时，证书 SAN 需包含该 IP。

将 `OF_ACCOUNT_REGISTRATION` 改为 `closed` 并重新启动区服，可以关闭注册，已注册账号仍可登录。网关和游戏区服分别运行，迁移时用发行包启动脚本的 `backup`、`restore` 子命令移交存档，部署好目标机器上的证书，再用同一数据目录启动两个进程。

## 访问范围与限流

- 玩家端共享同一 TLS 端口进行账号操作、游戏连接和公开资源读取，最低 TLS 1.2。照片、缩略图、公告图片和已发布版本附件支持 GET、HEAD。服主管理和本机账号绑定入口保持在本机。
- 每个来源 IP 每分钟最多提交 60 次账号请求。区服按同一来源分别限制注册 6 次、登录 30 次，其余账号操作共用 30 次。输入错误也计入次数，超额返回 HTTP 429。共用 NAT 出口的玩家会共用额度。密码等账号操作另有 3 个并发工作位。
- 网关从 TLS 连接读取来源地址，用该区服的本机密钥生成限流标识。区服验证标识、请求路径、正文和时间。公网提交的转发头会被丢弃；其余接口不会携带限流标识。默认允许 128 个并发网关连接，可用 `--max-connections` 调整到 1–2048。

## 停止

在网关终端按 Ctrl+C 停止接受玩家连接。在第三个终端运行 `./start.sh --state ./state/realm stop` 正常关闭区服；Windows 使用 `.\Start-Server.cmd --state .\state\realm stop`。服务管理器部署时，将网关和区服配置为同组启停。更新证书后只需重启网关。

## 游戏内二级密码

客户端的 `SPOperateReq` 支持开通、更改、验证和关闭角色的六位数字密码。开通状态跟随角色存档，每次重登重新验证。更改需输入旧密码，关闭需验证当前密码。区服只保存随机盐和 scrypt 校验值。连续输入错误五次后，区服暂停该角色验证 60 秒，这是本服规则。

国服资源表 4001 和提示文本 2244 可核对位数与数字格式。哪些玩法在原版 UI 中要求二级验证仍待实机核实。独立区服的账号密码用于启动器登录，导入备份请在角色首次进入游戏前操作。
