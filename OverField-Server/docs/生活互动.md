# 生活互动

## 钓鱼

在原客户端打开「互动」，选用钓竿和鱼饵。连续钓鱼时，客户端完成上一竿后再开始下一竿。区服在每竿结算时更新鱼饵、精力、耐久、鱼获和对应任务。取消、离开场景或掉线会结束未结算的一竿，重登保留已经结算的结果。

| 国服行为 | 当前区服规则 |
| --- | --- |
| 鱼饵与鱼种 | 60 种普通收获有明确的推荐鱼饵等级。符合推荐时提高相对权重。另有 4 种普通杂物和 3 种限时鱼获，限时鱼获需要在活动期使用特制鱼饵。 |
| 骨舌鱼 | 需要钓鱼 5 级，中型，昼夜均可。推荐 3 级饵，鱼长范围为 170–240。 |
| 技能与耐久 | 已学的小型、中型、大型鱼精通按技能参数影响相应体型。两条“用力过猛”事件按原表各扣 5 点耐久。空竿按正常结算消耗鱼饵。 |
| 任务与图鉴 | 鱼获入包并更新钓鱼记录。9 级任务“钓到大型鱼”只累计大型鱼。国服目标文本写 1 次，数值表阈值为 3，区服采用数值表。 |

国服 1.1.12 画面实见连续钓鱼记录、骨舌鱼入手、大中型鱼精通、空竿吃饵和耐久扣 5。公开配置给出鱼塘 1001 对应池 1001；基础钓获率、池内权重、事件触发率、等待时间、鱼长分布以及精通能否在同一竿叠加，仍待官服数据校准。推荐饵的具体权重倍率属于本服模拟值。

## 采集植物与捉虫

从「互动」装备采集手套或捕虫网，前往地图中的植物或昆虫点。区服按当前地图、点位和装备校验收获。国服点位表覆盖 8 张世界地图与 4 个副本，同一地图内去重后共 11,886 个点位。普通和幸运收获分别使用原表；同一次收获有多种产物时一并入包。图鉴按实际获得的数量累计，达到目标后手动领奖。

每位玩家分别记录累计次数、当日额度和幸运额度。区服按北京时间 05:00 换日。背包已满时不会消耗额度。导入全进度备份可以接续原登录地图的个人采集累计，导入后的当日额度从零开始。

原版客户端负责生成附近可见的候选点，并报告命中的收获与幸运状态。区服当前实现了已在国服广场备份中核实的规则组 0。特殊规则组分配、跨日额度恢复的细节、部分增益与季节刷新概率仍待核实。
