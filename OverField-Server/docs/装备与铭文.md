# 装备与铭文

玩家可以在原版装备界面锁定武器或防具、逐级强化、在武器上镶入或摘下铭文，以及在分解界面获得材料。每个操作都使用当前登录角色所属的装备实例。

强化读取该装备属性组对应的等级表，扣除本级的材料。达到配置上限时保留当前等级。镶入按铭文一级配置扣费，摘除免费。把铭文移到另一把武器会同步清除旧绑定；材料不足时保留原绑定。铭文始终保存在角色仓库。

分解返回装备属性组指定的材料。请求中只要有锁定、已穿戴、角色预设引用或仍镶有铭文的实例，整笔分解取消。强化、绑定、扣费和物品变化同时提交到角色存档。

可用 `tests/test_native_equipment.py --resources resources` 在临时区服验证这些操作、重复请求保护和重启后的存档。

## 角色外观与生活工具

每名探索员分别保存徽章、雨伞、六种采集工具、载具和宝具铲。原版外观面板一次提交十个槽，清空某个槽也会保存。徽章和雨伞按玩家持有的款式校验，八个工具与载具槽按本人装备实例校验。旧存档已配发的基础工具可以卸下再装回。切换当前队长时，其他玩家可在同一场景和频道看到该队长的外观。验证命令为 `tests/test_native_character_appearance.py --resources resources`。

## 藏宝图和宝具铲

国服商店 15000 的第 35 至 37 格可购买普通宝具铲、普通藏宝图和高级藏宝图。装备宝具铲后，选中背包中的地图，前往标示的场景和采集点完成挖掘。每张图有独立编号，消耗后仍计入考古图鉴。早期存档中缺少点位的图会在登录时补齐，保留原编号。

三把宝具铲的配表挖掘时长为 12、8、5 秒，成功率分别为 50%、80%、100%。交互与地面检测由原客户端执行，区服核对当前角色的铲、场景和采集网格，结算一次物品与奖励。宝物种类和份数读取国服奖池，具体随机权重采用社区的等概率规则。`tests/test_native_treasure_dig.py --resources resources` 验证购买、实例入包、挖掘、错误回滚与旧图迁移。
