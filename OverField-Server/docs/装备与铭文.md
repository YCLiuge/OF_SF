# 装备与铭文

玩家可以在原版装备界面锁定武器或防具、逐级强化、在武器上镶入或摘下铭文，以及在分解界面获得材料。每个操作都使用当前登录角色所属的装备实例。

强化读取该装备属性组对应的等级表，扣除本级的材料。达到配置上限时保留当前等级。镶入按铭文一级配置扣费，摘除免费。把铭文移到另一把武器会同步清除旧绑定；材料不足时保留原绑定。铭文始终保存在角色仓库。

分解返回装备属性组指定的材料。请求中只要有锁定、已穿戴、角色预设引用或仍镶有铭文的实例，整笔分解取消。强化、绑定、扣费和物品变化同时提交到角色存档。

可用 `tests/test_native_equipment.py --resources resources` 在临时区服验证这些操作、重复请求保护和重启后的存档。
