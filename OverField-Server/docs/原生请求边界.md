# OF_SF 原生请求边界

本页按国服 PC 1.1.12 的消息字段、资源表和已验证的区服行为记录证据。实际路由数量见[客户端请求对照](客户端请求对照.md)。

| 原生操作 | 当前依据与处理 |
| --- | --- |
| 继承奖励码 `InheritCodeUseReq` | 玩家提交 `code`，响应回传 `code_str` 和物品明细。上游按 `inherit` 类型发奖。本服支持服主发码、限额、到期与撤销，双角色原生协议回归验证了只领一次和重登后的余额。码只给当前角色发奖。继承旧 UID、名字和进度使用[个人进度导入](个人进度导入.md)。零售客户端输入该码的界面尚待确认。 |
| 场景通用子消息 `GenericSceneAReq` | 包含子编号 `generic_msg_id`、参数列表和映射。上游回显这三个字段，具体子编号对应的场景操作、前置状态和通知仍待确认。 |
| 取消账号名绑定 `AccountNameBindingCancelReq` | 请求无字段。上游回传当前 UID。国服界面操作对应哪种绑定、如何保存和重新绑定，尚缺独立依据。 |
| 冻结解除 `UnfreezePlayerActionReq` | 请求携带数字验证码。国服界面如何生成、提交并校验挑战待核实。 |
| 秘境星级奖励 `DungeonStarRewardReq` | 请求给出副本编号。国服 `Dungeon` 表中有 156 关配置三星计时，这些关卡均没有配置奖励、展示奖励或宝箱奖励类型。上游写明 100 金币为占位值。待核对关卡、达成条件和实领奖品后开放。 |
| 坍塌房间 `CollapseFailReq` | `TeamGameplay` 表的 100601 子模式有两条记录，指向同一坍塌地块资源。组队菜单只列 100101、100201。坍塌房间的开场、淘汰和结算规则尚待核实，目前返回模块关闭。 |

服主关闭了五个入口。实物收货地址读取和提交占两项，发行方设备日志授权、日志上传占两项。第五项 `UploadFGBytesReq` 对应 FairGuard SDK 上传二进制数据，区服返回失败，丢弃该数据。
