# 初始代币与收藏

区服首次创建角色或升级旧存档时，将每种已识别的游戏代币设为 **1,000,000**。当前共 47 种，包含金币、星石、菱石、喵币、招募券、扭蛋币及活动兑换货币。可用于换购的积分算作代币。体力、精力、经验、活跃度、掉落计数，以及通行证、月卡等付费状态继续沿用角色原值。

启动区服会先迁移已有角色。每个角色的发放记录与库存改动在同一 SQLite 事务中提交。玩家之后花费、领取、重登或迁服，余额都会保留。区服备份包含这项记录。

1.1.12 客户端配表中有 768 件带场景资源的家具、542 件带着装模型的服饰、231 个可播放的动作菜单项及 314 种聊天表情。两个菜单项可以使用同一段角色动画。首次发放只补缺少的收藏，保留原有件数、装备和染色。角色家园中已摆放的家具也算持有。动作解锁对应的条件和物品只涉及外观收藏。

原客户端的「手机 → 个人头像」可选择国服 1.1.12 头像表中的全部 **207 个头像**。原表有 40 项会在解锁前显示，另有 167 项随解锁出现。默认头像「菲」、原需探索员达到 20 级的「芙」「光」「格」，以及活动头像均可直接更换。新角色、已有角色和导入角色会各补齐一次头像贴纸，保留已有份数、代币余额和当前头像。备份中带有有效头像时，首次导入会接续原先的选择。更换头像后重新登录仍会保留。

原客户端可穿戴和切换角色的三组服装预设、隐藏饰品或辫子、向附近玩家展示动作和表情。服饰遵循原有部位、角色、性别与已解锁染色方案的要求。区服会保存签名、头像框、挂坠、手机壁纸和手机壳。头像框、挂坠、壁纸和手机壳沿用各自的持有及解锁条件。

## 活动签到与成就奖励

签到使用国服 1.1.12 的 28 张签到奖励表和对应活动实例的起止日期。每个角色在活动期间实际登录一天增加一天签到资格，区服以北京时间凌晨四点换日。同一角色同一活动的每档奖励只会入包一次。跨日仍在游戏中的角色可打开签到并领取。

成就页可查看单项进度、已领奖项目和分组状态。单项达到配表目标可领取奖励，整组全部达标后可领取组奖。国服表包含 11 个分组和 446 项条件，实际可领奖的范围取决于私服各玩法已记录的进度。领取和入包在同一次数据库事务内完成。
