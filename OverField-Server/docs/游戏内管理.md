# OF_SF 游戏内管理

在服务器目录执行以下命令。省略 `--state` 时使用启动器配置的默认数据目录。用本区服注册的登录账号，或游戏中显示的 UID 指定管理员。账号可在角色第一次进游戏前授权，UID 需在角色创建后使用。在线角色立即获得或失去权限。

```text
python of.py --state ./state/realm gm grant --account alice
python of.py --state ./state/realm gm revoke --uid 1000001
python of.py --state ./state/realm gm list
python of.py --state ./state/realm gm audit --limit 30
```

Windows 也可把 `python` 换成 `.\runtime-win64\python.exe`。首次启动区服后即可进行授权。

在原客户端的附近、世界或私聊输入框中发送 `/gm help`。命令和反馈只有发送者可见，聊天历史不保存命令。管理专用客户端也可发原生 `GmCodeReq.param` 并读取 `GmCodeRsp.result`。

| 输入示例 | 作用 |
| --- | --- |
| `/gm whoami` | 显示自己的本服管理员 UID |
| `/gm online` | 显示本服在线人数 |
| `/gm announce 今晚八点在广场集合` | 向当前在线玩家发送游戏内通知 |
| `/gm mail 1000002 活动安排已更新` | 向指定本服 UID 投递系统邮件，支持离线角色 |
| `/gm give 101 50` | 给自己的本服角色增加代币。支持 101、102、103，单次 1 至 1000 |
| `/gm moonspot place` | 在角色当前位置放置祈愿石信标，返回编号。同场景、同频道的玩家可见。 |
| `/gm moonspot move 1`、`/gm moonspot remove 1` | 将自己在当前频道放置的信标移到脚下或收回。每个场景频道最多 50 个信标，14 天后自动回收。 |

公告和邮件正文限 120 字，支持纯文本。授撤权、已执行命令及结果保存在该区服的 `game.sqlite`。公告、邮件审计保留正文，越权尝试按 UTC 日期、UID 和入口累计。备份和迁移区服时，这些记录随存档保留。
