# OF_SF 活动管理

在服务端所在的 `OverField-Server` 目录运行。先列出可用的原生活动，再将要调整的活动写入配置。区服运行时也可更新。

| 命令 | 用途 |
| --- | --- |
| `admin call events.catalog` | 查看支持的活动 ID、名称、原有排期和奖励。 |
| `admin call events.get` | 查看本区服保存的覆盖设置。 |
| `admin call events.set --input events.json` | 用文件中的完整列表替换当前覆盖设置。传入 `{"events":[]}` 恢复游戏表排期。 |

例如，让「每日甜点」按原有日程开放，可将下列内容保存为 UTF-8 编码的 `events.json`。保留其他自定义活动时，把它们一起写进同一列表。

```json
{"events":[{"id":4008,"enabled":true,"opens_at":null,"closes_at":null}]}
```

Windows 运行 `.\Start-Server.cmd admin call events.set --input events.json`。Linux 运行 `./start.sh admin call events.set --input events.json`。本机启动器自动开服时，改在启动器目录执行 `.\OverField-Server\Start-Server.cmd --state .\State\realm admin call events.set --input events.json`。

将 `enabled` 设为 `false` 可关闭活动。起止日期可填如 `"2026-11-25 05:00:00"` 的北京时间，或用 `null` 沿用原表。设置可缩短原活动窗口。活动页的奖励图标和数量来自 1.1.12 客户端内置表，服主可以挑选要开放的已有活动及其时间。

「每日甜点」位于「活动」页，角色当天登录即可领取，每天北京时间 05:00 刷新。每次获得精力药水 50 ml ×6、体力药剂 30 ml ×6、中瓶能量饮料 ×2。领取后道具进入当前角色的背包，使用药剂才会增加对应数值。

「新人支援」与「新人签到」是独立活动。新人支援按角色建号后的天数解锁七天任务，每天十项。七档奖励所需累计进度分别为 15、30、45、60、75、90、105，领取档位奖励保留进度。已有真实玩法记录的条件会计入，尚未接入的条件保持未完成。

本期通行证从角色实际的招募、副本等记录计算已接入的目标。高级礼包已一次性发放的付费奖励在页面里显示为已领。可配置的原生活动及数量以本机 `events.catalog` 为准。

## 罗塔广场海上舞台

用 `admin call plaza.catalog` 查看 58 条国服舞台记录、可选活动页和季节街机。`plaza.get` 显示本服安排。一个广场同时使用一个舞台和至多一台季节街机，可以有多个活动页。排期使用北京时间。

例如，在春节舞台同时开放「万家灯火」「巧日得春」和「罗塔年夜饭」，可将下面的 JSON 保存为 `plaza.json`。把日期改为本服的开放期，两端均包含所填秒数。

```json
{
  "theme": 23,
  "activities": [4010, 5087, 260212103, 260212104],
  "arcade": 12003,
  "opens_at": "2026-12-01 05:00:00",
  "closes_at": "2026-12-14 04:59:59"
}
```

Windows 运行 `.\Start-Server.cmd admin call plaza.set --input plaza.json`，Linux 运行 `./start.sh admin call plaza.set --input plaza.json`。传入 `{}` 恢复国服原表日程，保留独立的 `events.set` 设置。设定窗口内，广场列表控制七个主题页的开放项，也可额外排入 `plaza.catalog` 列出的扭蛋、沙袋等活动。将 `arcade` 设为 0 可在窗口内关闭季节街机。签到领取沿用角色原有的领奖记录。

| 对应内容 | 舞台和入口的依据 |
| --- | --- |
| 幽冥庭院 | 舞台 44 为万圣节，活动 260815130 引用剧情 910101。首期 5075 与复刻共用剧情，只能选择其中一期。 |
| 桂影同欢 | 活动页 260815020。它的国服原排期与摩天轮舞台 37–42 有交集，场景分多个建设阶段。 |
| 万家灯火、巧日得春 | 春节舞台 23。4010 是「万家灯火」主题页，260212104 与 260212103 是两项独立签到。 |
| 罗塔年夜饭 | 活动说明 5087，季节街机 12003。采购、合成、上菜和领奖使用区服的餐厅玩法。 |
| 半周年 | 舞台 22、45 使用半周年庆预制件。国服表未确认「为我们的相遇干杯」的独立活动 ID，舞台选项仅代表场景装饰。 |

活动和街机的开放状态随区服时间切换。已登录的玩家在下一次心跳接收菜单变更。要换海上舞台，请于活动期内正常退出并重新打开私服客户端。原生资源更新会获取本服清单。跨越排期结束时再重开一次，可载入原版日程。

原客户端按 `Scene.scene_theme` 的日期载入舞台。OF_SF 从校验过的 1.1.12 原包生成区服资源清单。以春节为例，117 张表中只有场景、活动和街机三张发生变化。开启沙袋时，还会调整 NPC 10301 的出场日期。已验证真实资源下载、哈希与 CRC、活动签到和餐厅协议。各舞台内的按钮、剧情及演出仍待逐项实机核对。

## 扭蛋、沙袋、锦鲤与活动礼包

- **扭蛋**。50 期活动使用 28 套国服奖池，可在 `events.catalog` 查看各档奖品与库存。复开指定期数时，把该期活动 ID 加入 `plaza.set` 的 `activities`。首笔单抽另有折扣，十连按实际抽数扣币。抽齐主题款后直接发放机台其余商品。各期库存和角色抽取记录在重登后保留。
- **暴打老李**。活动 260326150、260815150 使用广场 NPC 10301。个人宝箱、全服击打总数和已领奖档位分别保存。每日限额以北京时间 05:00 刷新。国服表给出了箱子产出上限和可能的道具数量，未给单击掉落概率。当前每次有效击打从仍有配额的档中等概率落一箱，达到配额后只累计击打次数。
- **谷雨垂钓**。鱼塘 1001 使用原版钓竿与鱼饵，角色面对水面后可以抛竿。钓竿耐久、鱼饵、精力、钓鱼职业经验和图鉴在收竿时结算。取消、切图或退出会结束尚未结算的一竿。64 种常规产物按等级、昼夜筛选，另有 3 种谷雨渔获，仅在国服谷雨商店档期使用特制鱼饵箱时加入。鱼身长度、技能效果、图鉴档位和奖励取自国服表。基础成功率、等待时长和鱼池权重使用社区实现与区服取值，仍待官服实测。
- **罗塔锦鲤**。活动 260326180 在活动期内按商城等值金额累计，每满 20 元的虚拟礼包送一张抽奖券，每人最多 30 张。刮券生成仅在本区服登记的兑奖码。兑换截止后仍可查看已有号码。活动关闭后，参与角色下次刷新或登录时，剩余券按每张 10 星石兑换。原版 4 月 11 日直播抽出的五个实物名额属于线下运营。重排时资源表中的兑奖截止时间同步调整，原界面说明图文仍写原日期。
- **活动礼包**。默认点选礼包即发全份内容。若想启用游戏内逐日领取，在 `events.set` 的指定礼包行增加 `"staged_gifts":true`，例如 `{"id":3001,"enabled":true,"opens_at":null,"closes_at":null,"staged_gifts":true}`。新领取该礼包的角色在满足国服表中的登录日数后逐档领取，旧版已整包发放的角色保留原收据。

## 重开历史签到、通行证与回归活动

将已列入 `plaza.catalog` 的指定期数加入该广场配置中的 `activities`。例如，第十五期通行证使用 260514070，第十六期使用 260625070。同一窗口可选择一个通行证赛季和多个签到或召回页。进入活动期后重开私服客户端，使本机活动资源与区服日历一致。重新排期保留原期数下每个角色已经领取的奖励。[截图中各期的核对结果](活动复刻核对.md)
