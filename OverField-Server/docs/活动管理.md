# OF_SF 活动管理

在服务端所在的 `OverField-Server` 目录运行。先列出可用的原生活动，再将要调整的活动写入配置。区服运行时也可更新。

| 命令 | 用途 |
| --- | --- |
| `admin call events.catalog` | 查看支持的活动 ID、名称、原有排期和奖励。 |
| `admin call events.get` | 查看本区服保存的覆盖设置。 |
| `admin call events.set --input events.json` | 用文件中的完整列表替换当前覆盖设置。传入 `{"events":[]}` 恢复游戏表排期。 |

例如，让「每日甜点」按原有日程开放，可将下列内容保存为 UTF-8 编码的 `events.json`。保留其他自定义活动时，把它们一起写进同一列表。

```json
{"events":[{"id":4008,"enabled":true,"opens_at":null,"closes_at":null}]}
```

Windows 运行 `.\Start-Server.cmd admin call events.set --input events.json`。Linux 运行 `./start.sh admin call events.set --input events.json`。本机启动器自动开服时，改在启动器目录执行 `.\OverField-Server\Start-Server.cmd --state .\State\realm admin call events.set --input events.json`。

将 `enabled` 设为 `false` 可关闭活动。起止日期可填如 `"2026-11-25 05:00:00"` 的北京时间，或用 `null` 沿用原表。设置可缩短原活动窗口。活动页的奖励图标和数量来自 1.1.12 客户端内置表，服主可以挑选要开放的已有活动及其时间。

「每日甜点」位于「活动」页，角色当天登录即可领取，每天北京时间 05:00 刷新。每次获得精力药水 50 ml ×6、体力药剂 30 ml ×6、中瓶能量饮料 ×2。领取后道具进入当前角色的背包，使用药剂才会增加对应数值。

「新人支援」与「新人签到」是独立活动。新人支援按角色建号后的天数解锁七天任务，每天十项。七档奖励所需累计进度分别为 15、30、45、60、75、90、105，领取档位奖励保留进度。已有真实玩法记录的条件会计入，尚未接入的条件保持未完成。

本期通行证从角色实际的招募、副本等记录计算已接入的目标。高级礼包已一次性发放的付费奖励在页面里显示为已领。可配置的原生活动及数量以本机 `events.catalog` 为准。
