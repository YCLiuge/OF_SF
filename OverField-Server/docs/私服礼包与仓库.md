# 私服礼包与仓库

打开 Windows 启动器，选好区服，点击「私服礼包」。用该服自己的账号登录，按中文名称筛选礼包，点领取即可。首次建角请先进入一次游戏。在线角色会收到背包变更，已建角的离线角色可在下次进图查看。不同区服各自保存记录。远端连接沿用选服时配置的 SSH。

礼包列表来自国服 1.1.12 的商品格。普通道具与附赠道具按所选格子发放，首领加赠按当前角色的领取次数计算。固定内容的礼包直接展开，自选礼盒保留在背包。活动礼包可直接获得该礼包配置的奖励，领取通行证档位会在首次领取该季时发放进阶档奖励。月卡赠送配置的道具并延长本服月卡，到期前每天可领一次日奖。本服的发放记录和物资在同一笔数据库事务中提交。

原客户端商城如能打开，点选其商品也可触发本服赠送。遇到「支付未开放」提示，可查看背包，或用启动器领取。该提示来自关闭真实收银台的步骤。启动器里的免费领取始终使用私服自己的角色和背包，不产生消费。商城显示的现金标价只来自原客户端资源。

## 玩家物品

区服用 `identity.sqlite3` 保存账号、凭据校验值与档案关联，`game.sqlite` 保存角色和物资。可堆叠物品以角色和道具 ID 定位，独立装备按角色和实例 ID 定位。衣装保留自己的染色方案。探索临时背包有 30 格，支持整理、丢弃、穿戴、主动入库和返回花园自动入库。银币等物资直接入库存档。标识和背包格数来自国服配置。

整服迁移在停服后使用服务端 `backup` 和 `restore`。备份包含两个数据库和对应角色的礼包、抽卡与背包进度。角色福利与消费后的余额见 [初始代币与收藏](初始代币与收藏.md)。
