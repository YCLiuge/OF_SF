# 上游玩法对照

2026-11-24 核对了 byzp/of-ps 的 main 分支，提交为 [fe890434](https://github.com/byzp/of-ps/tree/fe8904344ef376b21dd4c248e5072bf975b873d8)。OF_SF 最初采用的提交为 [fa2142b](https://github.com/byzp/of-ps/tree/fa2142b8521e802beb23fc6ed538205b9f4f1513)。

两个项目共享 Python、Protobuf 消息和部分处理器。上游从 `main.py` 启动游戏服务、HTTP 服务和可选的跨服通信；OF_SF 的 `of.py` 管理区服生命周期，`app/local_game_service.py` 管理 TCP 会话、SQLite 事务和同频道广播。服主通过 CLI 或本机 HTTP 接口管理数据，备份可在两个平台之间迁移。移植玩法时需核对国服表、请求进入条件、奖励通知和旧存档；同名处理器只说明两边接收了同一类请求。

## 本轮移植与剩余差异

- **营火**。放置、移除、同频道广播、切线重入、停服恢复和到期熄灭已接入。消耗取自国服 `Expression` 表，三种营火各扣一份对应材料，持续 180、300、480 秒。OF_SF 允许放置者主动收回场上的营火，已消耗的材料不返还。范围和时间由本服校验。[上游放置处理器](https://github.com/byzp/of-ps/blob/fe8904344ef376b21dd4c248e5072bf975b873d8/handlers/PlaceCampFire.py)
- **养成材料速刷**。国服 `QuickObtaining` 表列出 24 项，按角色等级选择产量和价格。体力和星石两种确认入口分别扣费，领取数量必须符合对应档位。体力每消耗 1 点发 10 点队长经验，倍率沿用社区实现。材料、货币及经验随事务一并保存。[上游材料速刷](https://github.com/byzp/of-ps/blob/fe8904344ef376b21dd4c248e5072bf975b873d8/handlers/ItemSweep.py)
- **普通秘境扫荡**。国服资料能确认哪些关卡允许扫荡和展示哪些奖励，但实际掉落及倍率仍需核对。该入口继续返回未开放状态。
- **染色和照片墙**。上游已有染色、选色和照片检索逻辑。接入 OF_SF 前，染色需验证扣料失败时保底计数和颜色可一并回滚，照片墙需同时验证上传、查询、收藏与跨角色权限。[上游染色](https://github.com/byzp/of-ps/blob/fe8904344ef376b21dd4c248e5072bf975b873d8/handlers/OutfitDye.py) · [上游照片检索](https://github.com/byzp/of-ps/blob/fe8904344ef376b21dd4c248e5072bf975b873d8/handlers/PhotoShareSearch.py)

私服协议实测覆盖上表所列的操作。大部分测试直接连两个独立角色，涵盖重登、存档恢复及异常输入。原版 Unity 的各活动页面和完整主线仍需逐项实机验证。多人小游戏的完整对局、全部赛季活动、所有副本和跨区服联机尚未完成官服等价验证。

遇到差异时，记录所在玩法、点击顺序、预期结果与私服实际显示。启用阶段诊断后，可在 `stage-failures.jsonl` 查看失败请求，在 `stage-operations.jsonl` 区分同一请求中的已知操作。操作记录仅包含请求类别、枚举或已知教学事件编号，不含对话文本和账号。若需要对照官服，请只记录相同玩法的界面操作，不必向服主提供账号凭据或登录抓包。

在源码根目录运行 `python tools/compare_upstream.py /path/to/of-ps`，可以对比直接注册和通过工厂注册的处理器。加上 `--audit 完整报告.json` 可同时列出上游有处理器、而当前国服区服会返回未开放状态的请求。完整报告由 `tools/audit_requests.py --verify-all --full` 生成。

上游源码有 295 个专用请求处理器。当前客户端的 303 项请求及逐项验证情况见[客户端请求对照](客户端请求对照.md)。仍有部分邮件附件、时装染色、家园房间装饰和秘境扫荡待补。专用请求、连接层处理及通用实现的代码位置不同，实际覆盖以游戏动作和回归结果为准。[广场入口实测](广场入口实测.md)
