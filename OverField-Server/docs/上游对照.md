# 上游玩法对照

本次核对的社区版本为 [byzp/of-ps @ fe890434](https://github.com/byzp/of-ps/tree/fe8904344ef376b21dd4c248e5072bf975b873d8)。开始对照时的服务端基础版本为 `fa2142b`。本服直接使用自己的数据库、私服认证和管理接口。

| 模块 | 当前范围 |
| --- | --- |
| 招募 | 常驻、配置多个 UP、原生历史自选、单抽/十连、保底与按角色抽卡记录。常驻池的默认基础概率与保底按国服客户端的招募说明设置，服主可调整权重和保底。 |
| 仓库与探索袋 | 存档随角色保存，支持入库、排序、装备和回花园结算。 |
| 礼包与月卡 | 原生私服礼包窗、商品格到账、首领加赠和月卡日领。 |
| 制作 | 家具、手工艺与纺织使用对应配方、材料、精力和熟练度。 |
| 秘境 | 配置目标推进、前置通关记录、重复结算保护。随机装备候选按已发布的名称、图标与装备表筛选。 |
| 世界等级 | 角色等级和试炼记录决定可解锁的等级，降低与恢复均保留在角色存档。 |
| 联合演算 | 14 赛季、42 个关卡。支持挑战、队伍入场、开战、离场、继续或终止、好友榜和积分领奖。每次挑战按配置消耗一枚对应入场券。伤害按客户端上报值及关卡剩余生命结算。赛季排名邮件、原版战斗画面待验证。 |
| 餐厅活动 | 4 套主题支持采购、合成、上菜、刷新及领奖。原活动表仅为其中两个主题列出历史排期。原版客户端当前能否展示这些入口仍待实机确认。 |
| 多人队伍 | 同服建队、邀请、换队伍模式、队长管理、离队/解散和重登恢复，人数和队名上限可调。 |
| 装备 | 仓库里的装备可锁定、强化、镶入/摘除铭文和分解，服务端检查所有权及使用状态。 |
| 签到与成就 | 按活动可领取日期发放签到奖励，达成后可领单项和组奖；按角色只入库一次。 |
| 角色外观 | 货币和收藏迁移、穿戴与隐藏、邻近玩家外观通知、聊天表情和角色资料。 |

私服协议实测覆盖上表所列的操作。大部分测试直接连两个独立角色，涵盖重登、存档恢复及异常输入。原版 Unity 的各活动页面和完整主线仍需逐项实机验证。多人小游戏的完整对局、全部赛季活动、所有副本和跨区服联机尚未完成官服等价验证。

遇到差异时，记录所在玩法、点击顺序、预期结果与私服实际显示。私服日志 `stage-failures.jsonl` 可帮助定位请求。若需要对照官服，请只记录相同玩法的界面操作，不必向服主提供账号凭据或登录抓包。

仓库中的 `tools/compare_upstream.py` 可读取本机已有的 byzp/of-ps 源码检索专用请求处理器。例如在本仓库根目录运行 `python tools/compare_upstream.py /path/to/of-ps`。结果按请求名对比，私服通用处理器、登录分发以及运行时生成的处理器需另查源码。

对照涵盖上游 295 个原生请求。部分邮件附件、宠物捕捉与分解、家园方案和秘境扫荡仍缺少对应操作。专用请求、连接层处理及通用实现的代码位置不同，实际覆盖以游戏动作和回归结果为准。[广场入口实测](广场入口实测.md)
