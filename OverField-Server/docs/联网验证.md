# 国服 PC 1.1.12 私服的在线身份验证

原客户端在所选区服的游戏 TCP 连接上发送 VerifyLoginTokenReq，内含 QuickSDK 给予客户端的 UID 和登录令牌。本组件在该阶段提供可选的在线核验，成功后进入本服 PlayerLogin 和角色主数据流程。角色、物品和剧情保存于本服。更改区服发现地址与 SDK 验证是独立步骤。

启用前请确认运营方允许本服使用该产品的身份校验服务。客户端的 SDK 始终与它原有的发行方交互。服务端的唯一验证目的地为本机安装版中实际配置的发行方域名和 QuickSDK 文档指定的接口路径。凭据通过 TLS POST 发送。服务校验证书链及主机名，只在接口明确返回成功且确认 UID 时放行。未知响应、网络故障、HTTP 重定向和拒绝都导致登录失败。日志不记录 UID 或登录令牌，本服数据库使用本服密钥对应的 UID 摘要来绑定角色。

## 服务端设置

在启动服务的终端或环境配置中设定以下变量，再启动服务。

- OF_QUICKSDK_VERIFY_URL 可以设为 https://sdkapi-of.inutan.com/webapi/checkUserInfo 。留空时只启用独立私服票据。
- OF_QUICKSDK_CREATE_PLAYERS=1 允许首次通过该发行方校验的玩家自动获得本服独立角色。默认 0，管理员可在现有资料上执行 bind-sdk --profile 档案文件，交互输入 SDK UID。解绑使用 unbind-sdk --profile 档案文件。
- 国服发行方核验仅供同机玩家个人使用。OF_BIND 保持 127.0.0.1。远程部署使用本服档案和一次性游戏票据，通信使用 HTTPS 或管理员控制的加密专网。

原生会话接口和首次建档已用合成测试账号验证。实际国服 HTTPS 接口已用一份不包含账号或令牌的空请求确认 TLS 有效并返回拒绝。Windows 本机联机测试中，国服 1.1.12 原版客户端随后通过真实 SDK 登录并进入本地私服的 3D 地图。发行服务可用性、面向社区运营者的权限及其接入条件由发行方决定。
