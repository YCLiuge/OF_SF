# 招募卡池

国服 PC 1.1.12 已有的常驻卡池为 `2000`，同时上架 `3023`、`203014`、`203015` 三个在 2026-11-24 日期范围内的 UP 卡面，以及可在历史自选入口使用的 `3000` 和 `3001`。常驻使用道具 `104`，UP 池使用 `110`，单抽 1 张，十连 10 张。限时卡面仍按原客户端本地日期显示。永久的原生自选入口 `9000` 支持 14 个历史 UP；服主上架其中至少一池后，可在这个入口选择已上架池并抽取，选择随账号保存。原版定义此入口每账号累计上限 70 抽。序章招募按原任务发放指定角色，服主调整普通卡池不影响教学。

服主可调整上架状态、保底次数及各个奖励组的权重。权重单位是万分之一，单池合计须为 10000。同组内各物品等概率。默认常驻四组的权重依次为 7900、1200、700、200。默认 UP 池将最后 200 分为常驻高稀有角色组 100、该期 UP 角色组 100。以上为私服默认值。

以下完整配置只上架一个 UP 池，保底为第 50 抽。选用其他期时，同时更换池号和对应的 UP 奖励组。

```json
{
  "pools": [
    {"id": 3000, "enabled": true, "pity": 50,
     "weights": {"100": 7900, "200": 1200, "300": 700, "400": 100, "3000": 100}}
  ]
}
```

本版资源表中常驻和上述 UP 池都没有免费单抽标志。跨日不赠送免费次数，保底不会清零。命中保底目标组后重新计数。各池保底独立存储，下架不删除历史。映像按独立实例入库；重复角色转换成角色表指定的碎片 1 件。常驻池达到原版配置的累计次数后可自选一次。福利预先发放的角色仍可完成教学，已有等级与装备保留。

服务器在同一个存档事务中扣票、发奖并记录历史。同一连接重发最近 64 笔带请求编号的成功普通抽取时，服务端返回原结果。原协议仅传池号和单抽开关；断线重登后可查招募记录，再决定是否继续抽。

服主管理命令为 `gacha.catalog`、`gacha.get`、`gacha.set`。导出和更新 JSON 的完整命令见[本机管理接口](本机管理接口.md)。
