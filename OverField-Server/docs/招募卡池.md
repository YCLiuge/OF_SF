# 招募

| 入口 | 招募券 | 玩法 |
| --- | --- | --- |
| 常驻招募（2000） | 常驻券 | 单抽 1 张，十连 10 张。最多 10 抽获得 SR 或 SSR 探索员，最多 70 抽获得 SSR 探索员。 |
| 限时 UP | 限定券 | 按原版卡面排期展示，消耗和记录按池保存。 |
| 新手自选（9000） | 限定券 | 选择已开放的历史 UP 后抽取。原版累计上限为 70 抽。 |

国服 1.1.12 的 11 月 25 日资源共有 115 张卡面，比 11 月 7 日多 16 张探索员复刻和 48 张映像卡面。区服可配置 113 池。另两张自选入口（9000、9001）随候选池开放，玩家先选目标再抽。新手折扣池最多 50 抽，新手自选最多 70 抽。

区服使用客户端资源中的消费、奖励组和保底奖励。基础权重和部分保底次数采用本服规则。完整旧默认配置自动补齐新池；自定义配置只继承已设原池的对应复刻，包括关闭状态与概率。打开招募页时，原客户端按本地编号匹配卡面，部分历史版面仍受客户端日期和教学进度限制。

核对报错时同时看角色与卡面日期。爱、辉、米莉亚的原池分别为 3000、3004、3006，对应复刻为 903000、903004、903006。莫莉「雾都侦探」原池 3023、复刻 903023 共用保底奖励组 3023，发放探索员 202002。爱「幻想同人女」另有 3 月 25 日结束的复刻（203020），对应卡面文本和抽取方式编号 3020。区服在编号唯一时将卡面编号归到同一期，消费、历史和保底共用一份。运行 `tests/test_native_gacha.py --resources resources` 可在隔离区服验证各期单抽、十连、历史与重复请求。

首次正常进图的新账号获得 29 位有战斗模型、技能及初始武器的探索员，均从基础星级开始；背包覆盖 670 种可生成装备实例的武器、采集工具和骑乘装备。队长仍可从瓶中小径开始主线，广场教学单抽固定为「诗」，已拥有时发放转换奖励。旧角色沿用原队伍；首次入图前继承的账号沿用备份。

每张招募结果分别携带主卡、重复角色的转换材料以及额外奖励。十连的十张主卡保持抽取顺序，重复送达的同一网络请求只结算一次。

历史 UP 示例为 **虎虎狮妹（3002）**，UP 探索员为**寅（朱寅）**。进入「招募 → 新手自选」选择该池，再单抽或十连。该卡面原属 2025 年，位于历史自选列表。

### 附加奖励

| 本次结果 | 外观券 | 重复获得时另发 |
| --- | ---: | --- |
| SR 映像 | 50 | 星砂 ×15 |
| SSR 映像 | 500 | 星尘 ×20 |
| SR 探索员 | 500 | 五星前给晋升凭证 ×3、星尘 ×3。已达五星给星尘 ×12 |
| SSR 探索员 | 1,500 | 五星前给晋升凭证 ×3、星尘 ×16。已达五星给星尘 ×40 |

首次获得映像时只附赠外观券。同一张映像在一轮十连中重复出现，也按重复获得结算。单抽与十连共用保底计数，重登后继续累计。可在「历史记录」核对结果。

### 服主设置

在服务端目录执行以下命令，可单独上架测试池，保留其他卡池、概率和保底设置。若区服由启动器提供，请在启动器目录将下例中的 `.\Start-Server.cmd` 换为 `.\OverField-Server\Start-Server.cmd --state .\State\realm`。

```powershell
'{"id":3002}' | .\Start-Server.cmd admin call gacha.enable
```

Linux 使用 `echo '{"id":3002}' | ./start.sh admin call gacha.enable`。十连会分别结算每一抽的奖励明细，并将同种附赠品的最终余额一次写入背包。扣券、发奖、历史和保底一并提交。

玩家重新打开招募页读取配置。`gacha.catalog` 列出可用卡池和奖励组。`gacha.get` 导出当前设置。`gacha.set` 用完整的 `pools` 列表替换设置。

常驻池默认基础概率为 SR 映像 92.20%、SSR 映像 0.80%、SR 探索员 6.00%、SSR 探索员 1.00%。服主可调权重，总和为 10000。常驻小保底用 `sr_pity`（默认 10，0 关闭），大保底用 `pity`（默认 70）。[管理接口与存档路径](本机管理接口.md)

## 罗塔优选

4000 号池每次十连消耗 3,600 外观券，至少获得一件时装。默认权重为染色剂 9%、家具 50%、紫色武器 35%、金色武器 4%、时装 2%。愿望单和招募池的保底分别保存在每个角色名下，服主可通过 `gacha.get` 和 `gacha.set` 调整卡池。国服配置提供愿望单初始概率和每次增长值，均为 5 个百分点。本服先做常规十连和时装保底，再对未抽中的愿望项应用本轮加成。此结算顺序仍待官服记录校准。
