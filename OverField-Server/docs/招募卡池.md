# 招募卡池

国服 PC 1.1.12 已有的常驻卡池为 `2000`，同时上架 `3023`、`203014`、`203015` 三个在 2026-11-24 日期范围内的 UP 卡面，以及可在历史自选入口使用的 `3000` 和 `3001`。常驻使用道具 `104`，UP 池使用 `110`，单抽 1 张，十连 10 张。限时卡面仍按原客户端本地日期显示。永久的原生自选入口 `9000` 支持 14 个历史 UP；服主上架其中至少一池后，可在这个入口选择已上架池并抽取，选择随账号保存。原版定义此入口每账号累计上限 70 抽。序章招募按原任务发放指定角色，服主调整普通卡池不影响教学。

服主可调整上架状态、保底次数及奖励组权重。单位为万分之一，每池合计 10000。常驻池默认采用国服招募说明公示的基础概率。

| 奖励组 | 类型 | 常驻默认权重 |
|---|---|---:|
| 100 | SR 映像 | 9220（92.20%） |
| 200 | SSR 映像 | 80（0.80%） |
| 300 | SR 探索员 | 600（6.00%） |
| 400 | SSR 探索员 | 100（1.00%） |

常驻池默认最多连续 10 抽获得至少一名 SR 或 SSR 探索员，最多连续 70 抽获得一名 SSR 探索员。单抽与十连累计，获得探索员时重置对应品质的计数。映像只增加计数。两个保底同时到期时发 SSR 探索员。

常驻池的可选字段 `sr_pity` 可填 0–1000，省略时取 10，填 0 关闭 SR 探索员保底。`pity` 可填 1–1000，控制 SSR 保底。保存过的权重和 `pity` 继续生效。各组内采用等概率抽取。UP 池使用私服设定，默认权重依次为 SR 映像 7900、SSR 映像 1200、SR 探索员 700、常驻 SSR 探索员 100 和该期 UP 探索员 100。

以下完整配置只上架一个 UP 池，保底为第 50 抽。选用其他期时，同时更换池号和对应的 UP 奖励组。

```json
{
  "pools": [
    {"id": 3000, "enabled": true, "pity": 50,
     "weights": {"100": 7900, "200": 1200, "300": 700, "400": 100, "3000": 100}}
  ]
}
```

本版资源表中常驻和上述 UP 池均需消耗招募券。各池保底独立存储，跨日、重登或暂时下架均保留进度。常驻池达到原版累计门槛后可自选一次。教学保留已有角色的等级和装备。

常规每抽附带外观券。SR / SSR 映像分别获得 50 / 500 张，SR / SSR 探索员分别获得 500 / 1500 张。映像按独立实例入库，重复 SR 映像另得 15 星砂，重复 SSR 映像另得 20 星尘。重复 SR / SSR 探索员在五星前获得 3 个对应晋升凭证及 3 / 16 星尘，五星后获得 12 / 40 星尘。领奖界面和背包同步显示本次所得。

服务器在同一个存档事务中扣票、发奖并记录历史。同一连接重发最近 64 笔带请求编号的成功普通抽取时，服务端返回原结果。原协议仅传池号和单抽开关；断线重登后可查招募记录，再决定是否继续抽。

服主管理命令为 `gacha.catalog`、`gacha.get`、`gacha.set`。导出和更新 JSON 的完整命令见[本机管理接口](本机管理接口.md)。
