# 服主公告与版本发布

服主在服务器上执行下列命令。Windows 使用服务端随附的 runtime-win64/python.exe，Linux 使用 runtime-linux/bin/python3.12；也可以使用发行目录中的启动脚本传递相同参数。每次指定的 --state 应对应正在提供游玩的角色库。命令在运行中的私服生效，公告、当前版本和附件纳入该区服的正常停服备份。

## 发布系统公告

准备 UTF-8 纯文本文件 `公告.txt`，每条正文最多 1600 字，标题最多 96 字。重复执行 `announce` 可发布多条公告。原客户端和启动器显示最近 12 条有效公告，每条最多可配 4 张 PNG 或 JPEG，单张至多 4 MiB，宽高均至多 4096 像素。游戏在下次拉取公告时取得新内容，启动器可点击「刷新」。

```text
python of.py --state state/realm announce --title "间隙开放" --body-file 公告.txt --image 封面.png --image 地图.jpg
python of.py --state state/realm maintenance-info
python of.py --state state/realm edit-notice --id 1 --body-file 新正文.txt
python of.py --state state/realm edit-notice --id 1 --clear-images
python of.py --state state/realm withdraw-notice --id 1
```

发布命令会输出公告编号。编辑时使用该编号，省略 `--image` 会保留原配图，重复传入 `--image` 可按指定顺序替换配图。服务端将图片写入区服数据库，备份迁移时会一起保留。撤回后，共用同一张图的其他公告仍可显示该图。

## 发布私服版本

准备目标玩家可以手动使用的安装程序或压缩包，后缀支持 .exe、.zip、.7z、.tar.gz，单文件上限 4 GiB。把本次发行已经核对的 SHA-256 填入命令。更新说明文件为 UTF-8 纯文本，最多 1200 字。使用递增的三段或四段数字版本号。

```text
python of.py --state state/realm publish-release --version 1.1.13 --file OF_SF-update.zip --sha256 <正式发行的64位小写SHA256> --notes-file 更新说明.txt
python of.py --state state/realm withdraw-release
```

发布时服务端复制并校验安装包，将验证后的附件存入 state/realm/release-files。正常服务只公开当前发行的附件。停发版本后可发布更高的版本号。准备下一次更新时应预留一个新附件的临时空间。

玩家从选定区服的公告查看版本、说明、文件名和 SHA-256。其更新地址固定为该私服的只读路径 /private/releases/加上校验值。跨机时走与选服一致的 SSH 信任。启动器保存后，由玩家决定何时退出游戏并手动安装。私服版本号与 Unity 官方资源清单各自维护，现有客户端资源镜像仍按 1.1.12 已知哈希校验。
