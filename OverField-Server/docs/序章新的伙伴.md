# 序章「新的伙伴」服务端

国服 PC 1.1.12 序章条目 1000001 接受后，角色在私服的原生 Quest 数据表记录首个任务 100011。会话通过 AcceptQuestReq、NpcTalkReq 和 QuestNotice 推进。重登时 PlayerMainDataRsp.quest_detail 返回该角色的已存进度。

| 阶段 | 原始条件 | 场景中的交互区域 | 结果 |

| 100011 去咖啡厅问问情况 | 11000111，NPC 10002 梓，对话 1000112，一次 | 罗塔花园广场 9999，梓的箱形触发器，中心 X 19.922、Z −26.662，宽 3.983、深 5.340 | 100011 完成，100012 开始 |

| 100013 使用“招募”获得1名队员 | 11000131，原条件类型 38，一次 | 需要一次有效的招募事件 | 常驻池 2000 单抽消耗一张 104，获得诗（102001）及配置指定的战术双剑。完成 100013 |

地图交互按原场景内 NPC 监听器在水平面的投影核对角色坐标。Unity 内人物胶囊与触发器的三维接触边界尚未复现。原始条件与场景资料可以验证剧情对象、位置、对白和顺序。原版客户端实际登录本服后是否发送同样的交互帧仍需端到端验证。

完成三个目标后，通过 ClaimQuestRewardReq 领取剧情条目 1000001 的原始奖励池 2010101。已领取标记写入章节 10000，重复领取不会再次发奖。
