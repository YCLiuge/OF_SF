# 私服账号与原版起名

启动器的「私服账号」使用当前选择的区服。账号可用 3–40 个汉字、英文字母、数字、点、下划线或短横线。英文字母大小写等效，全角英数字按半角处理。同一区服内不能注册等效的账号名。密码为 8–128 个字符。

游戏名为 1–16 个可显示字符，区服统一去重。新账号注册时可以填游戏名。留空后，原版 Unity 会在首次进图前显示起名和生日界面，名字冲突可重新输入。现有角色使用本区服签发的个人档案绑定新账号，UID、背包、任务和家园沿用该角色。旧档签发方法见《远程玩法》。

本机自动开服允许注册。独立部署时，服主可以在启动服务的环境中设置账号注册开关。已注册账号在关闭注册后仍能登录；持有旧角色个人档案的玩家仍可绑定自己的旧档。Windows PowerShell 示例：

```powershell
$env:OF_ACCOUNT_REGISTRATION = 'open'
.\Start-Server.cmd start
```

Linux 示例：

```sh
OF_ACCOUNT_REGISTRATION=open ./start.sh start
```

要关闭注册，将值改为 `closed` 并重启区服。密码在区服内以独立随机盐和 scrypt 校验值保存，普通登录签发的游戏票据默认 90 秒过期，成功使用后失效。可搬迁的区服备份同时保存角色和账号校验数据。登陆器通过 TLS 连接所选区服。可输入服主提供的 IP、域名或带端口的地址，未填端口时使用 18443。

这版 TapTap PC 1.1.12 的零售客户端启动时仍调用发行方渠道验证。选定的私服账号决定实际进入的角色：本机启动器将该账号与自己刚启动的 Unity 进程绑定，远端模式再向选中私服的一次性票据服务申请进场。收到密码的只有玩家选中的私服。纯私服协议客户端可以直接用区服签发的票据登录。

玩家在同一台电脑开多个区服时，请在注册前核对地址。备份及迁移使用同一个 `--state` 路径，避免误开一个新的空服。

r6 登陆器启动原客户端时会在 90 秒内用登录票预约该进程的首次进场。本机和 r6 公网区服可等待热更一小时。原客户端通过渠道验证后才能使用预约；预约仅限同一进程，使用一次即失效，区服改密也会立即撤销。r5 公网区服保留五分钟时限。超过时限请退出游戏，在登陆器重新登录。

公网玩家可主动核实账号。先输入账号并填写区服显示的五位数字，再查看该账号是否已注册。公开注册和旧档绑定都需要验证码。已有账号仍可用旧补丁登录；多次输错密码后需要新版补丁完成验证码。关闭注册时，已注册账号仍能登录。

验证码与后续核实票各有效 120 秒，使用一次后失效，仅供签发它的区服、来源、账号和对应操作使用。一次错误作答即需换图。区服分别限制全站、来源、用户名和来源与用户名组合的验证码请求。若反向代理合并连接来源，同一出口玩家共享来源配额。已注册和未注册账号输错密码时收到相同应答，服务端执行相同成本的口令校验。可信回环服务保留原有运维入口。

玩家在登陆器的「修改密码」核对当前区服、输入原密码和两次新密码，成功后使用新密码登录。新密码为 8 至 128 个字符。多次输错原密码时，需通过本区服的验证码。

忘记密码时，服主可在管理台「玩家账号」按登录名、游戏名或公开 UID 精确查找，核对角色后重置密码。管理接口分别为 `accounts.find` 和 `accounts.reset`。改密和重置都会撤销尚未使用的游戏、续连、存档导入和礼包凭据。在线角色可继续本次游玩，下次登录需使用新密码。
