## 客户端规则与共性缺口

- 章节解锁按前章目录内每个故事的领奖状态计算。另有地图门槛时，原客户端读取指定场景的完成进度，乘以 100 后与配置百分比比较。已核对 9 张小地图的 3793 个标记。在樱庭世界，45/456 积分未达 10%，激活原生区域装置后增至 46/456 并达到门槛。普通宝箱和重复操作不加分。独立的故事显示条件会查看前置故事起始任务是否已有状态。国服服务端实际允许何时接取，还需实机核对。
- 额外剧情的原版解锁检查要求指定的前置任务达到完成状态，并检验等级。额外详情另检查配置日期。领奖走任务类型 9。额外故事从各自场景自然接取的全流程仍待实机验证。
- 广场 7 名 NPC 的委托面板与限时活动对话以类型 0、实际任务 ID 接取。委托的 286 条原版配置按本人靠近对应 NPC、角色等级及前置委托生效。地图锁和任务显示条件决定锁定预览。原生测试实走七个池的首条委托及一条后续委托，验证了角色隔离与重登。活动 5075、260815130 在各自开放期分别接取 910101，结束后拒绝新接取。未逐项验证 286 个委托的完整交付或该活动的剧情收尾。
- 在主线目录的 539 个条件中，机关交互有 277 个，任务对话 114 个，完成任务 70 个，进入场景 62 个。其余包括秘境、遭遇、招募及区域解锁。类型 44 在任务 100032 对应星云树解锁「二段跳」，类型 168 在 100086 对应实际制作料理，类型 113 在 100093 以万分制计数，目标 1000 为樱庭世界 10%。100086 与 100093 已从预置当前任务开始，通过真实烹饪、地图收集跨越门槛、接续下一步并验证重启和角色隔离。62 个切图条件均有原生协议测试。其中 61 个普通目标从预置已接任务测试切图、后续步骤与重复切图，另一个在「初入空间」从头走通。「星云树」还自然覆盖了这 61 个普通目标中的一项。不因单步通过增加完整故事的计数。其余目标的场景、触发条件和步骤奖励仍须逐项核对。100053 有两组连续目标；100073 的同一阶段有三个目标。
- 原生实机、隔离协议测试和数据索引对应不同证据。完整验证应包括依序接取、实际交互、达标、状态推送、奖励入库与重登。服务器回复成功或客户端能打开回顾页只覆盖其中一项。

## 复查

从源码仓库根目录，在已导入 1.1.12 资源的环境中运行。报告逐任务列出条件组、场景、接取、交互、结算、发奖和重登证据；不会写入当前角色存档。

```sh
python tools/audit_story.py --server OverField-Server --verify --full --output story-audit.json
```

要核对原客户端额外的对话、NPC 和随机事件索引，加上 `--client-tables` 指向本地 1.1.12 完整 JSON 表目录。此目录无需随源码发布。省略 `--full` 可只输出分母与已验证故事编号。
