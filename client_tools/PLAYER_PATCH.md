# OF_SF 玩家补丁 · Windows x64

需要已安装并完成资源更新的 TapTap 国服 PC 1.1.12（11 月 7 日资源）、Windows 10/11 x64 和服主提供的玩家网关地址。

1. 把 ZIP 完整解压到独立文件夹。双击 **OF_SF 玩家补丁.exe**。
2. 选择含 `launcher.exe` 的原游戏目录。在「区服地址」填服主给出的完整地址，如 `https://realm.example:18443`。若服主使用自签 CA，核对来源后点「选择 PEM」。该证书只用于补丁与所选区服之间的连接。
3. 补丁与游戏在同一 NTFS 卷时，工作位置可留空。若在不同卷，请选择**原游戏同卷**的独立工作位置。程序会在其下创建 `OF_SF-Player-1.1.12`。启动前会核验游戏版本和可用空间，静态大资源复用硬链接，程序、可写缓存、存档和区服设置使用独立文件。
4. 启动器选定区服后，游戏直接沿用该选择。要切换可双击补丁目录的「区服设置.cmd」，选择新地址。
5. 首次使用可勾选「创建新私服账号」。游戏名可留空，在游戏内首次创建。填本服账号密码，点「进入游戏」。原版客户端仍需发行方在线渠道验证。服务器地址可保存，密码和票据仅用于当次登录。
6. 退出私服后可直接从原有 TapTap 入口启动官服。要移除补丁，请正常退出游戏，打开补丁点「清除补丁数据」，再删除解压目录和专用工作子目录。远端角色进度保存在服主服务器。

**导入已有角色进度**　在启动器填写已注册、尚未进入游戏的私服账号，点「导入角色进度」。选择全进度备份工具 v1.5 的玩家 ZIP、`snapshot.json` 或结果目录，点「预览备份」。预览显示备份的游戏 UID、角色名、恢复地点和可迁移项目。默认沿用可用的原 UID 和角色名。遇到占用可选择本服 UID、原有本服名字或另起名字。核对后点「确认导入」。在首次进入游戏前，可用同一账号打开此页，点「撤销上次导入」。进入游戏后将关闭撤销。旧本机缓存备份缺少服务端角色快照。原始报文、账号凭据和设备资料留在本机。

包内包含玩家界面、回环验证前端及 Windows 运行时。游戏本体由已有安装提供。服主需部署支持 OF_SF 玩家 TLS 网关的新服务器。此入口不支持普通游戏 TCP 端口、SSH 端口、网页代理或离线游玩。
