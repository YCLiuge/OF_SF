# OF_SF 玩家补丁 · Windows x64

需要已安装并完成资源更新的 TapTap 国服 PC 1.1.12（11 月 7 日资源）、Windows 10/11 x64 和服主私下发送的区服邀请或连接资料。

1. 把 ZIP 完整解压到独立文件夹。双击 **OF_SF 玩家补丁.exe**。
2. 选择含 `launcher.exe` 的原游戏目录。点「导入区服邀请」，选择服主私下发送的 `.ofinvite` 文件，确认来源和 CA 指纹后点「测试连接」。如果服主分开发送 HTTPS 地址和公开 CA，可在「手动连接设置」中输入。通用包和朋友包都可以直接公开分发。邀请为明文，任何持有人都能读取其中的连接资料，只应私下交给获准加入的人。
3. 补丁与游戏在同一 NTFS 卷时，工作位置可留空。若在不同卷，请选择**原游戏同卷**的独立工作位置。程序会在其下创建 `OF_SF-Player-1.1.12`。启动前会核验游戏版本和可用空间，静态大资源复用硬链接，程序、可写缓存、存档和区服设置使用独立文件。
4. 启动、选服及导入存档页面均以「我的区服」显示连接。游戏沿用启动器的当前选项。切换时可双击「区服设置.cmd」，选择已有区服或再导入邀请。需要查看明细时点「手动连接设置」。服主也可在这里点「导出已保存区服邀请」，文件保存在本机用户的 `%LOCALAPPDATA%\OF_SF\PrivateConnections` 目录。
5. 新玩家填写想使用的本区账号和密码，点「仅创建账号」。角色名可留空。**有备份**时先点「首次进游戏前导入存档」，预览并确认，再点「进入游戏」。**从头开始**可直接点「进入游戏」。已有账号直接填写账号密码。原版客户端保留发行方在线渠道验证。连接资料保存在本机，密码和票据仅用于本次会话。
6. 游戏中途断线时，先在游戏里确认重连。若原会话已结束，补丁会在当前游戏前台打开登录页。填写本区账号和密码，点「重新登录并进入游戏」。若已关闭此页，双击「区服设置.cmd」可重新登录并正常重开游戏。
7. 退出私服后可直接从原有 TapTap 入口启动官服。要移除补丁，请正常退出游戏，打开补丁点「清除补丁数据」，再删除解压目录和专用工作子目录。远端角色进度保存在服主服务器。

**导入已有角色进度**　在启动器填写已注册、尚未进入游戏的私服账号，点「首次进游戏前导入存档」。选择全进度备份工具 v1.5 的玩家 ZIP、`snapshot.json` 或结果目录，点「预览备份」。预览显示备份的游戏 UID、角色名、恢复地点和可迁移项目。默认沿用可用的原 UID 和角色名。遇到占用可选择本服 UID、原有本服名字或另起名字。核对后点「确认导入」。在首次进入游戏前，可用同一账号打开此页，点「撤销上次导入」。进入游戏后将关闭撤销。旧本机缓存备份缺少服务端角色快照。原始报文、账号凭据和设备资料留在本机。

包内包含玩家界面、回环验证前端及 Windows 运行时。游戏本体由已有安装提供。服主需部署支持 OF_SF 玩家 TLS 网关的新服务器。此入口不支持普通游戏 TCP 端口、SSH 端口、网页代理或离线游玩。
