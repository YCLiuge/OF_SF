《开放空间》国服 PC 1.1.12 联网私服

在这台电脑开始
双击“开放空间私服.exe”。游戏由原版 Unity 的 launcher.exe 运行。选择本地区服并确认，在海滨标题画面单击进入。首次登录沿用原渠道的正常授权流程，需要联网。进入的是本私服自己的角色和存档。

换一台 Windows 电脑
把“开放空间私服安装.exe”和“OverField-1.1.12-LocalInstaller-Win64.iso”放在同一目录，运行 EXE。已有对应版本的 TapTap 客户端也可直接选它作为游戏来源。默认安装位置是与安装器相邻的“联网私服”。首次导入 ISO 时，程序会先校验媒体，再将游戏文件直接提取到目标目录，目标盘建议预留 28 GiB。两个安装文件一起构成全量安装介质。
已装原游戏时，同一 NTFS 卷上的静态资源优先使用硬链接。这次在 D 盘复用了约 23.6 GiB。跨盘安装或从媒体导入会实际写入这些资源。整个已准备好的“联网私服”目录可复制到别处继续运行。
“区服设置.cmd”打开连接设置。单机上同时运行游戏及联网区服时，选择本机自动开服，保留默认回环地址。

迁移区服
Windows x64 使用 OverField-OnlineServer-1.1.12-Windows-x64.zip。
Linux x86-64 使用 OverField-OnlineServer-1.1.12-Linux-x86_64.tar.gz，在解压后的 OverField-Server 目录执行 ./start.sh start。两份专用包均附相应平台的运行时。
本机自动开服的档案和玩法数据保存在安装目录 State/realm。需要备份该角色时，退出客户端，在安装目录打开 PowerShell，依次运行下面两行，等待停服完成后执行备份。
& '.\OverField-Server\Start-Server.cmd' --state '.\State\realm' stop
& '.\OverField-Server\Start-Server.cmd' --state '.\State\realm' backup '.\realm-backup.zip'
在新服务器的空存档目录，用 ./start.sh restore realm-backup.zip 恢复，再运行 ./start.sh start。Windows 用 Start-Server.cmd 代替 ./start.sh。备份包含区服存档目录中的角色、账号资料及服主发布内容。私服个人档案 JSON 请另行保管。独立服务端使用自己的默认 state/realm，手动指定的数据路径应始终一致。

在游戏电脑上连接自己的服务器
在远端服务端目录创建个人档案。Windows 用 Create-Player.cmd，Linux 用 ./start.sh create-player --nickname 星桥。把这名玩家的 JSON 档案安全地交给本人。保持服务端监听自己的回环 18881 和 11033，玩家用自己有权限的 SSH 账号接入。
在游戏电脑上准备好 Windows OpenSSH 客户端、公钥登录和已经确认过的服务器主机指纹。在“区服设置.cmd”中选择 SSH 远端模式，填写 SSH 目标和端口。可登录远端的私服账号，也可以选择远端签发的个人档案来接入。第一次绑定自己的档案时勾选相应选项。客户端仍向本机的登录入口连接，本机验证渠道身份后使用远端私服自己签发的票据进入游戏。角色、任务和物资由远端服务端保存。详细部署与存档说明在 OverField-Server/docs/远程玩法.md 和 OverField-Server/部署说明.md。
要从新服务器继续玩现在这个自动创建的角色，先正常退出游戏并停服，在安装目录运行下面一行，给原角色签发私服个人档案。
& '.\OverField-Server\Start-Server.cmd' --state '.\State\realm' issue-profile --out '.\我的私服角色.json'
多个角色时可加 --nickname 和游戏内昵称。签发后重新执行 backup，把这份新备份还原到目标服务器。或者先还原旧备份，再在目标服务器的存档目录对原角色签发档案。SSH 设置中选择该 JSON。拥有私服档案密钥的人可以登录对应角色，分享安装包时请使用发行文件。

账号和首次起名
打开「区服设置.cmd」，选择自己的服务器，然后点「私服账号」。注册需要账号、密码。服主开放注册和旧档绑定见 OverField-Server/docs/私服账号与起名.md。填写游戏名会为你预留该名字，留空会在首登时进入原版游戏的起名画面。区服统一管理游戏名，重名可重新填写。要接着玩原角色，在「绑定旧角色」功能选择该角色在私服签发的个人档案，并设置自己的账号、密码和名字。创建新账号会创建新的私服角色。
这版 TapTap 游戏在进入玩法前还会执行发行方渠道登录。启动器使用当前选定的私服账号决定要加载哪个角色。密码仅在该区服校验，服务器存储加盐的密码校验值。远端服务器的账号通过选定的 SSH 连接使用。
在原版 Unity 的选服列表选择「添加或更改服务器地址…」，在弹出的地址输入框保存或应用。游戏内按住 Alt 可以唤出鼠标指针。
游戏名片上的绿色挂坠是补给箱。在本服的计时结束后可以领取，领取会更新背包并开始下一轮计时。调查页的「间隙」显示发现的入口和已参加队员的调查进度。

频道和家园
默认公共频道为 1 至 99999，每个账号在当前公共频道能放 1 件家具。离开该频道后家具归还背包。玩家 UID 从 1000001 开始；对应号码是该玩家的私人家园。主人和访客的摆放上限分别为 500 件和每人 1 件。附近聊天送达当前频道；世界聊天按独立的世界分区送达；私聊由对方和自己查看。世界分区默认为 1 至 9999。
服主可以用 rules 子命令查看和设置频道范围、UID 起号、摆放限额和世界分区。区服运行和迁移见 OverField-Server/部署说明.md，参数示例见 OverField-Server/docs/频道与家园设置.md。
服主可同时发布多条图文公告、编辑配图、撤回公告和发布版本附件。玩家可在「区服公告」查看版本说明、下载并校验附件。使用方法见 OverField-Server/docs/服主公告与版本发布.md。

玩法适配范围
已适配的原版交互包括序章的一部分、调查派遣、间隙、角色动作、部分秘境、背包与商店交易、家园家具、好友及聊天。完整主线、限时活动、全部多人玩法仍在逐项验证。部分奖励数量和宝箱掉落沿用开放源代码私服的数据。游戏内出现问题时记下操作、所在频道和大致时间。服务端 State/realm/stage-failures.jsonl 记录失败回复的消息编号与状态码，State/realm/stage-events.jsonl 记录最近的处理阶段。

脚本与 agent 可在本目录运行 of-launch.cmd schema、of-launch.cmd status。服主管理接口见 OverField-Server/docs/本机管理接口.md。
